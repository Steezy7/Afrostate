# AFROSTATE Launchpad

Build a complete, production-quality website for a young streetwear fashion brand called AFROSTATE.

I have attached the official AFROSTATE logo to this project.

IMPORTANT:

The attached logo is the source of truth for the brand identity.

Do NOT redesign the logo.

Do NOT simplify it into a black-and-white logo.

Do NOT remove the leopard print, navy blue, cream, yellow/gold, cartoon-like character, or the existing visual personality.

The website should be designed AROUND the logo.

1. OVERALL CREATIVE DIRECTION

AFROSTATE is a young streetwear brand.

The website should feel:

Fun

Young

Energetic

Playful

Bold

Fashion-forward

Slightly rebellious

Culturally expressive

Internet-native

Social-media friendly

Visually memorable

It should feel like a brand that young people would discover on:

Instagram

TikTok

WhatsApp

Snapchat

Pinterest

The website should make someone think:

"Wait... this brand is actually cool."

It should NOT feel like:

A corporate company

A generic clothing Shopify template

A luxury fashion website trying too hard

A SaaS landing page

A portfolio website

A generic African-themed template

An AI-generated website

The design should have personality.

2. IMPORTANT — USE THE LOGO AS THE VISUAL STARTING POINT

The supplied logo contains:

Deep navy blue

Cream/off-white

Leopard print

Black

Warm yellow/gold

A playful illustrated/cartoon character

Bold handwritten/script-like typography

Use these visual cues throughout the website.

Primary colors should be approximately:

#0B1B4B

Use yellow/gold and leopard print as energetic accents.

The leopard pattern should be used sparingly as a visual texture/accent rather than covering every section.

16. PHONE VALIDATION

Support Nigerian phone numbers.

Accept:

08012345678

and:

+2348012345678

Normalize phone numbers before storing them where appropriate.

Prevent obviously invalid phone numbers.

If a phone number already exists:

Show:

YOU'RE ALREADY IN.

Do not create duplicate waiting-list records.

17. SUBMISSION EXPERIENCE

When the user clicks:

On success:

Large text:

"Welcome to AFROSTATE."

Make the success state feel exciting.

Do not use a generic browser alert.

18. SUPABASE BACKEND

Use Supabase as the backend.

Create a table:

waiting_list

Fields:

id

full_name

phone_number

email

created_at

If email is optional, allow NULL.

Use proper database constraints.

Automatically generate:

created_at

Use UUID or another appropriate primary key.

19. DATABASE SECURITY

Do NOT expose Supabase service-role credentials in the browser.

Use environment variables.

Enable Row Level Security.

The public website should only be able to submit waiting-list records.

Anonymous visitors must NOT be able to read the waiting list.

Anonymous visitors must NOT be able to update records.

Anonymous visitors must NOT be able to delete records.
